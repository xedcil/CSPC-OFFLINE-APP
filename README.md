# GO APP · Social, Cultural and Political Change · Grade 12 Week 8
Offline learning web app (PWA) for DSDSNHS, built from the Grade 12 Week 8 ILAW DLL.

## Upload to GitHub Pages (no coding tools needed)
1. Log in at github.com, click **New repository**. Name it `g12-cspc-week8`, set it to **Public**, click **Create repository**.
2. On the empty repo page, click **uploading an existing file**.
3. Unzip this folder, then drag ALL files inside it (not the folder itself) into the page:
   `index.html, sw.js, manifest.json, seal.png, icon-192.png, icon-512.png`
4. Click **Commit changes**.
5. Go to **Settings > Pages**. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
6. Wait 1 to 2 minutes. Your link will be `https://<your-username>.github.io/g12-cspc-week8/`

## For learners
1. Open the link ONCE while online (phone data or school Wi-Fi). Wait for the page to fully load.
2. Android Chrome: tap the menu (3 dots) > **Install app** or **Add to Home screen**.
   iPhone Safari: tap Share > **Add to Home Screen**.
3. After that, the app opens with no internet. Progress is saved on the phone.

## Updating the app later
Edit `index.html` on GitHub, then change the version in `sw.js` (example: `v1` to `v2`) so phones download the new copy.
Use a NEW repo for each week, or keep one repo with one folder per week.
